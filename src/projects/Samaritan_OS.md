# Samaritan OS (SAM-OS)

## Overview
A unified civic and operational operating system engineered for **The Samaritan Riders of Washington State (SROWA)**, bridging the Okanogan County Master Charter (OKMC) and the Spokane Satellite (SPCO).

Designed as an institutional modernization following the architecture of the **Okanogan County Fair OS**, Samaritan OS resolves key non-profit operational challenges:
- **Zero-Fee Online Donations:** Direct integration with Square Web Payments SDK featuring an automated Donor Fee Pass-Through formula ($100 donation -> donor pays $103.30 -> club nets 100% / $100.00).
- **WSGC Raffle Compliance Engine:** Bulletproof compliance with Washington State Gambling Commission rules (RCW 9.46, WAC 230-11-030). Prohibits illegal internet ticket sales while providing an in-person Square POS digital registry, consecutive physical stub range tracking, quota caps, and automated annual WSGC activity reporting.
- **Centurion Telemetry & Digital Plotters:** Eliminates annual paper Word document plotters by automating the 16 Minimum Annual / Contractual obligations, 25% base event threshold, and make-up ride calculations with 1-tap PIN/GPS field check-ins.
- **Multi-Tenant State & Satellite Cockpit:** Executive oversight for State President Robert "Cool Cat" Johansen and State Board, with autonomous dispatch for OKMC and SPCO.
